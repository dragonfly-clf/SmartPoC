#### URC - Update Router Concern


#### Description


The contract allows for the modification of the router address, which subsequently updates


the pair address. However, the contract does not to add the new pair address to the

`automatedMarketMakerPairs` mapping. This omission can lead to unexpected


behavior and potential issues with the contract's functionality.


#### Recommendation


It is recommended to include the necessary logic to add the new pair address to the


`automatedMarketMakerPairs` mapping when updating the router address. This can


be achieved by explicitly calling the appropriate function to add the pair address to the


mapping after the router address is modified.
