#### OTUT - Transfers User's Tokens

**Criticality** Critical

**Location** TrebolToken.sol#L36

**Status** Unresolved

#### Description

Any user has the authority to transfer the balance of a user's address if the user has granted

allowance. The contract does not subtract the allowance in the `transferFrom()`

method, as a result, the transfer can be repeated until the user's balance goes to zero.
```
 function transferFrom(address from, address to, uint value)
 public returns(bool) {
   require(balanceOf(from) >= value, 'balance too low');
   require(allowance[from][msg.sender] >= value, 'allowance
 too low');
   balances[to] += value;
   balances[from] -= value;
   emit Transfer(from, to, value);
   return true;
 }

#### Recommendation

```
The team is advised to subtract the allowance in the `transferFrom()` method and

migrate to a new contract.
